# 儀表板文字邊界與浣熊／猴子改版

依使用者要求修正 Nova 戰鬥儀表板，接續完成 ID 11 浣熊、ID 12 猴子。原版第二款遊戲維持既有 Boss 工廠與巡迴順序；不跑模擬器或實機試玩。

## 儀表板

原本內容使用固定內距，但九宮格金屬外框會隨可用寬度縮放。現在外框切片與文字內距共用 `NovaPanelMetrics`，HUD 內容保留完整邊角及額外 4dp 間隔。長關名限制單行、省略過長尾端；分數可縮字，裝甲／主武／副武獨立等寬一列，暫停按鈕保留 48dp 操作區。文字高度決定面板高度，避免較大系統字級被固定高度擠出邊界。

## 浣熊：夜匣貨運車

- 磁索於每輪第 1 秒鎖定，1.5 秒預告後搶奪；有道具時跟隨該道具，否則鎖定玩家舊位置。玩家離開半徑 90 的圈即可避開，擊破貨艙也會取消磁索。
- 偷到的道具記錄種類；偷玩家時只減一枚核心超載充能，充能不足／無敵時不偷。被偷道具立即從世界移除，避免同一幀又被拾取。
- 貨艙可擊破，返還所藏道具並開啟 3 秒承傷 ×1.8 窗口，12 秒後可重建。貨艙的返還事件去重；轉形時保留貨艙和內容，Boss 擊破也會返還剩餘內容。
- 50% 展開電子戰天線，真車換位、另外兩個位置生成低血量可擊破全息假體。真車有車轍與實體貨艙信標，假體有掃描線與斷續邊框，沒有接觸傷害。

## 猴子：擬神偵察機

- 每輪掃描固定記錄主武器、貓型與目標座標，之後換武器或移動不會改掉當次快照。1.5 秒預告後分別投射扇形彈、定向雷射、橘貓重球或黑貓帶向下缺口的環形彈。
- 30% 從偵察機變成機甲；25% 喚醒古代圖騰，增加一座延遲 2.8 秒回放的節點。回放較弱，仍使用原快照；節點可擊破，正在蓄力／發射的節點雷射同步取消。
- 同次傷害跨過 30%／25% 時合併演出；轉形與覺醒各只發生一次。8–10 秒散熱窗口承傷 ×1.6。
- 轉形／覺醒清除舊彈幕與回放節點，死亡清場不殘留雷射。

兩關包含專屬小怪、精英、背景、三形態 Boss、部件、子彈／特效、駕駛員與六段過關對話。通用科技升級道具繼續沿用。各加一個節點教學事件，保留原本小怪出場表。素材來源與切圖見 [美術說明](../art/nova-echoes/README.md)。

## 巡迴

已改版前十一站：狗狗 → 熊熊 → 卡皮巴拉 → 兔子 → 企鵝 → 無尾熊 → 水獺 → 熊貓 → 樹懶 → 浣熊 → 猴子。未改版一般對手僅剩豬豬，老鼠仍是最後冠軍。續玩保留已通關與已揭曉對手、分數及裝備，只重排未揭曉的部分。

## 驗證方式

```sh
source /workspace/.setup/android-env.sh
./gradlew testDebugUnitTest assembleDebug assembleRelease --offline --no-daemon --max-workers=2 --console=plain -Pkotlin.compiler.execution.strategy=in-process
```

新增測試涵蓋工廠隔離、貨艙返還與去重、轉形保留補給、磁索避讓／取消、同幀拾取防重複、假體擊破、武器快照、回放雷射取消、單次與分次跨門檻、變形中擊破、雙貓初始武器通關與 HUD 縮放內距。通關模擬使用固定種子與無敵模式，驗證戰鬥可結束，不代表實機手感或人工閃避驗收。UI workflow 保持手動觸發。
