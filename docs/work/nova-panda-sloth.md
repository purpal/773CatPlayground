# 黑貓裁切修正與熊貓／樹懶改版

依使用者授權，修正黑貓戰鬥圖左側異物，並接續製作 ID 9 熊貓、ID 10 樹懶。此批僅改 Nova 的工廠、資產路由及排序；原本第二款遊戲的 PandaBoss、SlothBoss 與巡迴規則不變。依既定要求不跑模擬器／實機試玩。

## 機制

- **熊貓「玄竹」**：履帶車階段放置兩座可破壞供能柱，電網有 1.4 秒預告；破壞任一端會取消連線，兩柱全毀可阻止下一次修復。每輪最多恢復 3%，整戰最多三次。40% 血量收納成球形載具，1.4 秒預告後沿鎖定的反彈路線行進 3.8 秒，停轉 2.2 秒承傷 ×1.8。預告與實際移動共用解析反射路徑；路線不追蹤玩家，保留畫面下方退路。回到上方的階段關閉接觸碰撞。
- **樹懶「時差」**：單一固定時序場，敵彈在場內以 0.3 倍移動，三個扇區於每輪 4.4／5.6／6.8 秒依序放行，每個閘門有 1.4 秒預告與 0.6 秒漸變。下一輪倒轉放行次序。35% 血量展成時序環，已開閘的場內流速變成 1.7 倍；邊界 40 單位內漸變回場外 1 倍。玩家、玩家子彈和遊戲時鐘不變慢。10–12 秒為核心散熱窗口，承傷 ×1.6。移除原版火箭掃擊及高速衝撞模板。
- 兩關各加一個可破壞節點教學事件，保留原本小怪出場表；有專用小怪、精英、背景、子彈、特效、駕駛員與六段過關對話。
- 黑貓異物來自共用圖等分裁切錯誤；從實際透明間隔 x=802 切開，而非舊中線 x=768。詳細來源與素材表見 [素材說明](../art/nova-forest/README.md)。

## 巡迴

新遠征：狗狗 → 熊熊 → 卡皮巴拉 → 兔子 → 企鵝 → 無尾熊 → 水獺 → 熊貓 → 樹懶 → 浣熊／猴子／豬豬隨機 → 老鼠終局。

續玩時保留已通關及已揭曉／飛抵的對手、裝備與分數，只將未揭曉的已改版關卡前移。
