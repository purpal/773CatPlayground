# Nova：固定機庫展示與第二、第三戰區

## 機庫與介面

選機頁沿用定稿的 45° 左前機體（16 格索引 2），不再輪播角度。尾焰、機身燈條以該影格的來源座標定位，1.6 秒漸亮、1.6 秒漸暗。駕駛員仍站在機體前方。彈性機體展示區配合固定底部按鈕；可用畫面測試的 720×1280 截圖檢查兩個按鈕同時顯示的情形。

`sectors/ui-frames.png` 包含儀表板與通訊框。採九宮格繪製，保留邊角比例，文字與互動控制項仍由 Compose 繪製。

## 素材與機制

素材位於 `app/src/main/assets/nova/sectors/`，區域矩形見同目錄 `manifest.json`。所有新增圖皆由 OpenAI 圖片生成工具製作；引擎只取圖與縮放，未修改原版美術。

| 戰區 | 素材／行為 |
|---|---|
| 加拿大楓林要塞（熊熊） | 楓林熔蜜工廠背景；蜜蜂攔截機、熔蜜砲台、熊型突擊機、蜂后菁英、蜂巢炸彈、鋸輪護衛；蜂蜜／針彈／衝擊球／星形彈；鑽頭、油罐掉落、爪擊特效；銅甲熊駕駛員 |
| 巴西熱泉中樞（卡皮巴拉） | 熱泉運河背景；鴨型攔截機、橘核浮雷、水壓砲台、小型巡邏艇、菁英炮艇；泡泡／種子彈／橘核飛彈／熱流彈；水砲與水柱、浮標掉落；護目鏡卡皮駕駛員 |

熊熊 25% 血量卸下鑽頭與油罐，改用能量爪。卡皮巴拉 50% 血量增加肩甲與雙水砲，25% 進入最後攻擊階段、掉落橘核浮標，機身換成空插槽的受損圖。沿用原本預警、傷害範圍、子彈路徑與攻擊時序。

兩關沿用狗狗關的科技風補給機、升級道具及玩家武器，不另建立外觀不同但功能相同的升級道具。

新 Nova 遠征暫時固定狗狗 → 熊熊 → 卡皮巴拉，後面保留其餘對手原有相對順序與最終鼠鼠。卡皮巴拉在原版屬於天王段，此次只提前新 Nova 遠征的出場，原版巡迴與既有存檔不變。
