## 使用資訊

`manifest.json` 記錄圖片實際尺寸、程式類型對照與取圖矩形。生成圖集的物件間距不是完全等分，尤其長形硬光骨頭；請使用各物件的 `source_rect_px`，不要直接假設每張都是規則等分圖集。

已驗證 PNG 可讀、素材圖集具有 alpha 通道、30 個取圖範圍皆有效且非空。特效周圍保留半透明亮光；圖片查看器若忽略 alpha，可能顯示彩色底光，請以支援透明合成的工具檢視。外緣色暈與小尺寸可讀性仍須在遊戲內確認。

背景未驗證上下無縫；整合捲動時需另行檢查接縫。光束外觀不能直接宣稱是可重複平鋪的紋理，長度、預警線、碰撞範圍與旋轉仍依程式繪製。

音波環圖是攻擊視覺參考，不代表要把既有一圈多顆 `NOTE` 子彈改成單一碰撞環。中央核心、敵人砲管與補給艙也不新增獨立玩法判定。後續仍需對齊碰撞圓、發射點、精英尺寸及實際畫面比例。

## Boss 攻擊與掉裝備補充

`boss-actions/` 新增四種艦體狀態、六種武器／掉落配件狀態、九款攻擊與卸甲特效。詳細的 35% 卸武器、25% 掉指揮裝甲片、投擲回收和雙雷射安全通道規則見該資料夾 README 及 manifest。
