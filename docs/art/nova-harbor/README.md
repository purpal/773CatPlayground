# Nova 眠巢／雙潮素材包

素材由 OpenAI 圖片生成工具產生，僅供第三款遊戲 Nova 使用。原始輸出留在工作區 `/workspace/generated_images`，遊戲素材位於 `app/src/main/assets/nova/harbor`。

| 檔案 | 內容 |
|---|---|
| bosses.png | 眠巢懸吊母艦／展足中間態／六足平台；雙潮姊妹潛艇／對接中間態／雙體戰艦 |
| enemies.png | 葉刃無人機、貓頭鷹砲台、袋鼠重裝精英、蓄能電容；魚形巡邏艇、貝殼砲台、河狸重裝精英、聲納浮標 |
| effects.png | 綠色能量彈、電球、核心艙門、放電環；魚雷、聲納彈、舷側艙門、尾流環 |
| pilots.png | 無尾熊司令、雙人水獺姊妹通訊肖像 |
| koala-background.png | 澳洲尤加利能源基地 |
| otter-background.png | 新加坡夜間聲納港灣 |

`manifest.json` 有 26 個區域。Boss 三形態固定畫布，不依透明邊界裁切改變大小；兩個水獺船體另有獨立區域供潛航換位使用。艙門、電容、浮標和放電／尾流特效分層繪製。碰撞以程式的船體／核心判定為準，背景水面與地面不造成傷害。
