# 喵神守夜：最後一座罐罐神殿

獨立的第五款遊戲，與《喵神封魔錄》的五路卡牌塔防分開。夜間神社、粗黑線條貓武將、硬邊色塊；六位神貓保住逐漸被人類遺忘的神話，也保住晚餐。

## 首版規則

- 六選四，每隻神貓只能佔一座神座；八個座位可選。初始供品 310。
- 點貓卡再點空座召喚；點已佔用神座升級或換座。換座 15 供品，保留等級與分支。
- 每貓兩條升級路線，首次升級選定後不可改；Lv.2 費用 100，Lv.3 費用 150。
- 三張地圖各 10 波、雙入口固定道路；擊殺產出供品，波間 +80。戰鬥中也可布防。
- 每波清空後三選一祝福，本局永久生效、不能重複選。暫停與祝福選擇期間不推進模擬。
- 神諭為所選已部署神貓的大招，全隊共享 32 秒冷卻。機關冷卻 27 秒，可使頭目破防 5 秒。
- 神殿耐久 20。耐久 >=17 三星、>=10 二星，其餘一星；前關通過解鎖下一關。
- 星星、四貓隊伍與柔和特效偏好獨立保存於 `cat_playground_nightwatch`；戰局中途離開不保存。
- 神社依累計星星出現鳥居、食堂、長明神殿的復興故事。首版沒有抽卡或付費養成。

## 美術與特效

`generate2dsprite` 技能 + 內建 `image_gen`（`art_source: host_image`）生成，依使用者上傳的五張貓武將圖片及宙斯貓設定做風格參考。圖片是生成角色立繪，沒有宣稱逐格動畫；遊戲以小幅跳動、命中閃爍與獨立程序技能特效表現攻擊。

`art/cats-source.png`、`art/foes-source.png` 是留邊修正版來源，使用技能 v0.6.0 的 `generate2dsprite.py process` 以 native_alpha 切圖與縮放。六貓採 2x3、九妖採 3x3（grid-rounding nearest）、384px 畫布、fit-scale .88、min-component-area 100、strict-qc。最終兩組 QA 均 pass，無 WARN/FAIL；早期碰到格線的草稿未交付到 runtime。

輸出順序對應 `nw_zeus/poseidon/nezha/athena/wind/earth` 與 `nw_foe_0..5`、`nw_boss_0..2`。API 型號與估價未由內建工具提供，不推估成本。道路、場景裝飾和技能光效由 Compose Canvas 繪製，角色美術由影像模型生成。

## 實機驗證

依使用者要求，不使用 Android 模擬器。執行 JVM 規則測試與 release 建置，觸控手感、效能與視覺由實機回饋調整。

```bash
./gradlew testDebugUnitTest assembleRelease -PnightwatchPreview=true
```

`nightwatchPreview` 只改 release：使用 `com.purpal.catplayground.nightwatch` 與「773喵遊樂園・守夜試玩」名稱，可和正式版並存，避免覆蓋正式版存檔。未提供正式金鑰時沿用 repo 的 debug 簽署 fallback；預覽版停用正式版更新提示。不帶此旗標時原有正式版識別碼、名稱與簽章流程不變。

實機建議：第一次魚市場使用宙斯＋波塞頓＋雅典娜＋哪吒；檢查召喚、換座、兩條升級、祝福、暫停/背景恢復、神諭、機關破防、過關星星、重新啟動後解鎖，以及柔和特效與二倍速。中途返回會詢問是否放棄戰局。

頭目在護罩未破時施放震懾，讓周圍神貓短暫停止攻擊與攔截；機關破防期間可阻止震懾。升級首次分支會顯示能力說明，選擇期間暫停戰鬥，避免閱讀時被偷襲。
