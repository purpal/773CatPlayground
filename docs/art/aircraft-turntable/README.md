# 選機畫面：機體八方向素材

定稿造型的橘銅重裝型與黑青敏捷型，各有一張 RGBA PNG 圖集、八個環繞方向。`approved-top-view.png` 保存已確認的俯視造型參考。

圖集以四欄、兩列排列，由左至右：

| 列 | 第 1 格 | 第 2 格 | 第 3 格 | 第 4 格 |
|---|---|---|---|---|
| 上列 | 正面 0° | 左前 45° | 左側 90° | 左後 135° |
| 下列 | 背面 180° | 右後 225° | 右側 270° | 右前 315° |

- `orange-turntable.png`：橘銅重裝型。
- `black-turntable.png`：黑青敏捷型。
- `frames.json`：實際圖幅尺寸、每格像素範圍與預覽對齊錨點。圖幅為 1774 × 887，不能假設每格都是同一個整數尺寸，請使用提供的矩形。
- `preview_anchor_px` 為各格可見輪廓的包圍盒中心（相對於該格），適合先做置中預覽；不是經過 3D 驗證的機體重心。

已檢查兩張圖集均有完整 alpha 通道，每格都有非空素材與透明邊界，主要輪廓不接觸分格邊界。原始生成檔仍保留在 `/workspace/generated_images`。

這些是依定稿造型生成的多視角美術，角度標記為名義方向，不是同一份 3D 模型的精確渲染。八方向可以製作分段旋轉預覽；接入前仍須播放檢視尾巴、裝甲與機翼的連續性及微調旋轉中心。更平滑的連續旋轉需要更多中間影格或 3D 模型；單純淡入淡出會造成重影，不等於真實角度插值。

本次僅新增美術與取圖資訊，未修改選機畫面或遊戲架構。

## Nova 十六方向展示

第三款遊戲現保留上述八張，新增 `app/src/main/assets/nova/orange-intermediate.png` 與 `black-intermediate.png`，各包含 22.5°、67.5°、112.5°、157.5°、202.5°、247.5°、292.5°、337.5° 的名義方向。實際交錯順序、來源圖檔與對齊錨點以 `app/src/main/assets/nova/turntable.json` 為準。

選機頁會先在背景執行緒載入全部影格，再以 3.2 秒一圈播放，角度交界短暫混合。補間圖仍是生成式多視角素材，並非 3D 模型的精確旋轉渲染。

狗狗關駕駛員頭像為 `app/src/main/assets/nova/pilot-dog.png`，採用與旗艦一致的酒紅裝甲及琥珀核心。超載圖騰直接沿用橘色／紫色貓吼按鈕符號，刻紋、能量環及放大動態由 Nova 渲染器繪製。
