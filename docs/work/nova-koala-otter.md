# 眠巢／雙潮與巡迴排序

使用者授權再製作兩關，並集中已改版關卡於前段。本批選擇連續的 ID 7 無尾熊、ID 8 水獺；與原規劃的批次順序不同，使用相同的機制定位。依使用者要求，不跑模擬器／實機試玩，以單元測試和建置驗證後合併發布。

## 戰鬥

- **眠巢**：9 秒循環，2–5 秒核心散熱。本體前段承傷 ×2；電容在 4.8 秒鎖定方向、6.2 秒放電，提前擊破即取消。30% 血量以 1.6 秒展足變形，前段雙電容改成左右輪替單電容與單側弱點艙門。平台本體保持一般承傷，開啟的側艙承傷 ×2。不用舊葉刃掃擊或突刺。
- **雙潮**：兩個真實船體共用生命。每 10 秒輪替魚雷與可破壞聲納浮標的來源，魚雷固定直線通道有 1.4 秒預告。前段每輪潛航 1 秒，有航跡和上浮位置提示，無敵占常態循環 10%。45% 血量對接為雙體戰艦，中央連接臂形成短距離聲納屏障（1.3 秒預告），5.4–8.5 秒單側舷門承傷 ×1.8。船橋不增加隱形第三個命中目標。窄船體在一般射距只接到初始擴散彈的中央彈，因此共血池使用該站基準血量 ×0.5，補償受擊效率。
- Nova 專用 `StageDef` 複本與 Boss 工廠隔離原遊戲。原始 KoalaBoss/OtterBoss 未修改。兩關各增加一個可破壞節點教學事件，保留原小怪出場表。
- 新增可選的 `damageIdentity`，預設為敵人自己；僅 Nova 共血部件指定相同對象。超載範圍、穿透彈及黑貓震動掌按這個識別去重。部件承傷倍率在轉交共血目標前計算，原版水獺部件仍為 ×1。
- 轉形取消舊節點、清除彈幕／雷射，擊破清除部件；掉落一次維修補給，恢復血量不重複變形。

## 巡迴

新遠征：**狗狗 → 熊熊 → 卡皮巴拉 → 兔子 → 企鵝 → 無尾熊 → 水獺 → 隨機五關 → 老鼠終局**。

隨機池為熊貓、樹懶、浣熊、猴子、豬豬，全部洗牌；Nova 不再將樹懶固定留在三天王位置。原遊戲的 Tour 規則不變。續玩舊存檔保留已通關、已揭曉／飛抵的對手、機體裝備與分數，只把尚未揭曉的已改版關卡前移，其餘保持原本洗好的相對順序。
