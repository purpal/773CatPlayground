# 柴犬隊長：獵犬型重裝巡航艦

對應現有日本「櫻花公園」狗狗關（`Stages.dog`，定義編號 2；世界巡迴的實際出場順序可變）。本輪僅新增造型候選，不替換執行時素材或修改遊戲邏輯。

`hound-cruiser-top.png` 為 RGBA PNG，正俯視、艦首朝畫面下方，沿用已確認主角機體的金屬與陶瓷裝甲質感。深紅、鐵灰、琥珀色搭配厚重肩甲，與橘銅及黑青主角機區分；犬耳形感測器和獠牙艦首提供獵犬意象，不直接放入動物頭部。

中央反應爐是視覺辨識焦點，並不表示新增獨立弱點判定。左右武器平台可用來表現現有招式；迴力鏢、音波環、衝刺與卸甲後雷射仍以現有 `DogBoss` 邏輯為準。

後續整合時需要對齊現有碰撞圓、攻擊發射點與 35% 血量的卸甲狀態。完整與卸甲版本、招式動態及小尺寸辨識度均尚未驗證，本張先供造型確認。
