# 月躍／霜脊戰區素材與整合

適用第三款遊戲 Nova，關卡 ID 5 兔子及 ID 6 企鵝。素材由 OpenAI 圖片生成工具製作；原始 PNG 保留於工作環境 `generated_images`，遊戲使用檔案位於 `app/src/main/assets/nova/frontiers/`。

## 素材

| 檔案 | 用途 |
|---|---|
| `bosses.png` | 兔子輪式車／展開中／跳躍機甲；企鵝破冰艦／分艏中／雙體平台，共六張 |
| `enemies.png` | 兔子偵察車、砲塔、精英、跳躍噴口；企鵝巡邏艇、砲台、海豹精英、可破壞冰障投射器 |
| `effects.png` | 兩種陣營的定向彈、能量彈、衝擊碎片與落地／解凍環 |
| `pilots.png` | 白兔指揮官、帝王企鵝艦長的通訊半身像 |
| `rabbit-background.png` | 英國月躍雷達試驗場，暗色中央道路與側邊設施 |
| `penguin-background.png` | 南極破冰航道，中央海面與側邊冰棚 |

`manifest.json` 記錄 24 個 sprite 窗口。圖集並非全部等距：Boss、彈體及個別精英依實際透明區域設定窗口，避免切到鄰格。載具本體維持未裁去透明留白的比例，其他 sprite 由既有載入器去除留白。攻擊提示與判定用相同座標與半徑繪製。

通用升級道具、補給艦與既有客串小怪沿用前面三關的科技風素材。沒有替換第二款遊戲的 `assets/art`。

## 行為與視覺

- 兔子在 40% 進行一次機械變形。車形每輪一跳，機甲每輪兩跳；預先標示落點編號，鎖定後不追蹤玩家。跳躍預告 1.25 秒、飛行 0.7 秒、落地散熱 1.5 秒。落地圈覆蓋本體接觸區，散熱時承傷 1.6 倍。衝擊彈留出朝下缺口。
- 企鵝在 55% 展開雙體。單體佈設一排冰障，雙體佈設錯位兩排；缺口有共同可通行區。投射器可打破，成形前有 1.3 秒預告，最後 0.6 秒解除接觸傷害並消散。所有冰障消退後才輪流射舷砲；下一輪結冰前會清除殘彈。
- 變形使用三張結構連貫圖片交叉淡入，配合輪廓環；變形期間停攻擊、無敵、無接觸判定。形態與原版的卸甲／增裝旗標分離。
- Boss 警告頁顯示各自的應對提示。兩位駕駛員各有六句過關通訊，保留任意處點擊繼續及返回航路。

## 驗證方式

依使用者本次指示，不跑模擬器、裝置或 UI 試玩。以 `NovaVehicleBossTest` 驗證狀態轉換、落點鎖定、缺口、清場、擊破與基本武器可完成戰鬥；原版單元測試一併回歸。美術完成素材檔與窗口檢查，實際裝置觀感及手感由使用者驗收。

巡迴順序維持前三站狗狗→熊熊→卡皮巴拉，兔子／企鵝在其後的隨機池中，既有存檔不重排。
