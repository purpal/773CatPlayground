# 柴犬隊長：攻擊與掉裝備補充素材

本組依現有 `DogBoss`、`Boss.update`、`World.onBossBreak` 與 `World.onBossPhaseChanged` 製作，只有美術及對照資料，沒有修改遊戲程式。狗狗是 **DISARM 卸甲型**，不會在殘血時加裝新武器。

## 艦體狀態（body-states.png，2 × 2）

| 位置 | 條件 | 外觀及裝備 |
|---|---|---|
| 左上 | 血量 > 60% | 完整艦體、正常核心、指揮裝甲片保留。 |
| 右上 | 35% < 血量 ≤ 60% | 警戒／受損外觀，指揮裝甲片及骨頭武器仍保留。 |
| 左下 | 25% < 血量 ≤ 35% | 骨頭武器永久被打飛，掛架受損，既有雙雷射發射口顯露；指揮裝甲片仍在。 |
| 右下 | 血量 ≤ 25% | 無骨頭武器、無指揮裝甲片，中央上方留下裝甲片插槽，保留原艦體與雙側砲台。 |

艦體四格都不烘焙外掛骨頭武器。原本 `LostProp.HAT` 的帽飾以可拆式指揮裝甲片表現；犬耳感測器不隨它消失。雙雷射是原設定的攻擊機構顯露，不代表新增 ARMOR 型裝備。

## 武器與掉落物（equipment.png，3 × 2）

上排：待機骨頭、蓄能骨頭、啟動硬光骨頭。下排：飛行／返回骨頭、卸甲後失能骨頭、掉落指揮裝甲片。

這些是同一種雙端機械骨頭的不同發光／損壞狀態。`ThrownBone` 已有每秒 900° 的旋轉及 2.4 秒往返軌跡，飛行狀態使用單張圖配合現有旋轉即可，不需要把飛行軌跡烘焙進圖。

`boneOut` 只在投出期間暫時隱藏持有武器，不應直接換成永久卸甲的破損艦體。35% 卸甲時會取消尚未返回的骨頭，清除 `boneOut`，並產生 `LostProp.BONE`；該掉落物與帽飾都是裝飾粒子，不可當成玩家可拾取升級道具。

## 攻擊特效（attack-effects.png，3 × 3）

上排：橫掃扇形預警、硬光橫掃拖尾、突刺預警。中排：雙雷射預警、雙雷射啟動、雙發射口蓄能。下排：左右衝刺拖尾、卸甲碎裂爆光、狂吠音波參考。

原招式順序：

- 血量高於 60%：骨頭迴旋彈、兩次突刺、吠叫彈環、投擲並回收骨頭。
- 血量高於 35%、不超過 60%，且未卸甲：橫向衝刺、110° 骨頭橫掃、投擲回收、飛盤風暴、突刺。
- ≤35% 且已卸甲：向兩側展開的雙雷射、密集狂吠彈環、衝刺、飛盤風暴、一般吠叫彈環。≤25% 掉帽飾，但不新增另一組武器或更換上述招式清單。

## 整合約束

- 以 `broken` 和 `phase` 組合選艦體，不能只用原本三種 `mood`；35%～25% 的卸甲與 25% 掉帽是兩件事。建議選圖優先序：`phase == 2` → `broken` → `phase == 1` → 完整。
- 骨頭閒置原點為 Boss 相對座標 `(168,129)`；原待機長度 190、寬度 28。骨頭使用中應隱藏閒置疊圖，避免同時出現兩支武器。
- 橫掃寬度 54、長度 760，預警 0.8 秒、有效 1.3 秒、伸出 0.18 秒，從 20° 掃過 110°。突刺預警 0.65 秒，長度依玩家距離計算。
- 雙雷射原點分別為 `(-40,20)`、`(40,20)`，寬度 26、預警 1 秒、有效 2.8 秒，初始偏離垂直各 14°，再向外掃 12°。正下方中央安全通道必須保留，預警與命中幾何仍由原程式決定。
- 狂吠素材是外觀參考；原本是多顆 `NOTE` 彈形成的環，不能改成實心範圍碰撞。
- 原本的衝刺仍是左右移動；卸甲後仍可能射出骨頭形小彈，不應因武器被打飛就刪除原彈幕。
- 核心、雷射發射口與掛架沒有新增獨立弱點或碰撞區。

`manifest.json` 保存名義分格、素材狀態、世界座標及時序對照。PNG 已驗證可讀、有 alpha 通道，19 個來源範圍均非空；生成影格的中心、比例、邊緣光及武器掛點仍須在遊戲播放時對齊。特效圖是造型參考，不是已驗證可平鋪或可直接取代碰撞幾何的紋理。
